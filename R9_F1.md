## Model and exact supplied-path law

The original six learned two-sided clearance parameters remain unchanged:

`d_f = s_f + T_f*v_f + relu(v_f²-v²)/(2*b_f)`

`d_l = s_l + T_l*v + relu(v²-v_l²)/(2*b_l)`

`c_t = min(log(g_f/d_f), log(g_l/d_l))`.

Absent sides contribute `+inf`; a constrained zero gap gives `-inf`.
Eligibility `E_t` is the shared structural/physical/conflict contract, separate
from willingness. F1 does not change geometry, reservations, longitudinal
update ordering, or conflict arbitration.

All eight parameters use plain softplus with no added floor. In particular,
`tau=softplus(tau_raw)` and `w=softplus(w_raw)` (rho/eta in the advice).
The persistent location remains zero. Draw `z_i ~ Logistic(0,1)` once per
identity lifecycle and `epsilon_it ~ Logistic(0,1)` independently per decision:

`T_i = min{t: E_it and c_it + tau*z_i + w*epsilon_it >= 0}`.

For finite eligible boundaries:

`h_t(z)=sigmoid((c_t+tau*z)/w)`;
`log h_t=-softplus(-x_t)`; `log(1-h_t)=-softplus(x_t)`.

Vetoes have exactly zero hazard. `c=-inf` and `c=+inf` remain exact deterministic
atoms with zero adjoints. A prior certain event leaves exactly zero subsequent
survival/event support. Unsupported event NLL remains infinite. Finite negative
log hazards stay scoreable even when exponentiating them underflows; there is
no probability floor, logit clamp, padded clearance, timer or forced decision.

From risk entry, conditional survival is `S_t(z)=prod_(u<=t)(1-h_u(z))`.
The defining integrated masses are

`p_t = integral Logistic(z) * S_(t-1)(z) * h_t(z) dz`,

`S_t = integral Logistic(z) * S_t(z) dz`.

Score `-log p_T` for an event and `-log S_C` for administrative censoring.
Mixing is at sequence level; marginal step hazards are never multiplied.
Events and exits terminate exposure. Junction/vanished exits are counted as
competing outcomes, not fabricated merges or claimed independent censoring.
The normalization test is on a fixed **no-competing-exit** path.

## Quadrature, convergence and gradients

`hybrid_log_masses(c,tau,w,order)` takes time on the **last** axis and returns
log event masses and log survivals at every supplied prefix. It uses float64,
positive composite Gauss–Legendre weights, and log-sum-exp conditional products.
The logistic prior is integrated in probability coordinates. Both infinite
tails are retained using log-CDF/log-survival interpolation, so far-tail latent
nodes do not disappear when ordinary sigmoid values round to 0 or 1.

The numerical mesh splits at each finite `-c/tau` and at offsets
`{-8,-1,0,1,8}*w/tau`. These are integration breakpoints, not behavioral
thresholds or a truncated latent support. Coincident knots carry zero mass and
are removed. The adaptive mesh is held fixed in backward: quadrature integrates
the derivative of the defining conditional law. Moving-grid differentiation
would introduce spurious derivatives at coincident knots. Independent-density
quadrature comparisons and numerical gradcheck verify this adjoint.

Finite quadrature approximates the exact integrals. **Order 32 is not a blanket
accuracy guarantee for arbitrary fits.** `hybrid_quadrature_report` compares
N/2N/4N and requires both refinements to agree within the previously registered
`1e-6` absolute parity tolerance for masses, summed sequence NLL and c/tau/w
gradients. Unsupported outcomes explicitly fail the certificate. The fitted
cohort must obtain its own certificate before qualification; increase numerical
integration effort if necessary, never constrain w to make a test pass.

Synthetic tests additionally compare orders 32/64/128 against an independent
logistic-density integral, including small w/tau, small absolute scales, and
extreme positive/negative logits. At `tau=w,c=0`, the closed-form oracle is
`S_t=1/(t+1)`, `p_t=1/[t*(t+1)]`, which also detects a redrawn-z implementation.

As `w -> 0`, finite-margin population-entry paths recover the selectable strict
law: `F_t=sigmoid(max_(u<=t:E_u)c_u/tau)`, `p_t=F_t-F_(t-1)`.
Repeated/decreasing finite boundaries have positive hybrid event support;
their strict-limit mass tends to zero. Exact atoms are tested separately.

Padding/never-eligible rows avoid quadrature. Ordinary no-reset scoring chunks
integrate their full path once. General within-chunk identity resets use the
streaming fallback. Grids grow with the supplied path; long fits still need
appropriate batching and measured numerical convergence.

## RNG and hard-forward/backward parity

Hybrid state explicitly carries `z`, identity/presence/lifecycle, `rng_seed`,
`rng_generation`, `decision_step`, last `epsilon`, boundary `history`, and
integrated `logS`. Initial stream keys are drawn once per slot, including future
birth slots. Thereafter 64-bit counter mixing keys draws by saved stream,
identity/generation and decision step. Counter zero draws z; subsequent active
risk decisions draw fresh epsilon. Presence reuse increments generation so
slots without explicit IDs still receive a new identity draw. Vetoed active
risk steps advance the decision counter, while epsilon cannot override a veto.
Identity metadata is RNG/lifecycle metadata only, never a boundary input.

The integer mixer uses intentional modulo-2^64 arithmetic and interior
52-bit midpoint uniforms, transformed to logistic variates without tail clips.
Supplied testing uniforms must be strictly interior. Switching neighbors does
not redraw z; unrelated identity changes cannot perturb an existing stream.
New births after resumption also use saved stream keys, so they do not depend
on unrelated global RNG consumption.

All carry tensors survive rollout chunk boundaries. Save the rollout `state`
and its short model history in checkpoint `extra` when resuming a live rollout;
save likelihood posterior carry too if resuming mid-sequence scoring. There is
no hidden Python RNG/generator to reconstruct. Tests save/reload these states
through the real checkpoint API, perturb the global RNG, and recover exact
future lanes, draws, probabilities and posterior state.

Rollouts execute **the hybrid sampled threshold**, not the strict threshold
with a soft loss. The hard forward is `c+tau*z+w*epsilon>=0`. The separately
configured `merge_st_width` differentiates a sigmoid of this same sampled
margin; this is a **biased straight-through estimator**, not generative noise
and not the integrated likelihood. Native rollout quadrature diagnostics are
detached; the likelihood term builds its own graph. Final accepted crossings
remain equal to proposals under the inherited latent-independent reservation
contract. Coupled post-willingness arbitration would require a new joint law.
