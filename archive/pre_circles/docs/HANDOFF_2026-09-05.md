## 1. One-paragraph status

The project is an IEEE IV paper on **escalating from decentralized CAV
damping to a coordinated moving wall**. The wall's delay value **changes
sign with loading** (cost below ~2450 veh/h, savings above ~2600).
Damping alone is **neutral-to-harmful**. The escalate-or-not decision is
**one-dimensional** (a fitted loading threshold; a multi-feature model
does not beat it). Onset is **highly predictable** (OOF AUC 0.944).
Hold duration is **regime-dependent** (short at the boundary, long above
it). The frozen treatment is: **engage at onset, hold D(loading) ∈
{300, 450, 650} s, 5 s taper, return to damping**. Stage 2 generation
(the training set for that policy) is **specified and partly coded, not
yet launched**. Prospective seeds 4601–4660 and 5001–5060 remain
untouched.

## 2. Paper framing (do not change without the owner)

**Architecture the RSU runs:**

```text
detect onset  ->  check CAV supply (Gate F)  ->  compare loading to
fitted threshold (Gate B / whether)  ->  if escalate, set hold from
loading (how long)  ->  release to damping
```

**Claims (in this order):**

1. **Damping does not scale.** Frozen analytical
   `idm_analytical_disturbance_p30_v1` is neutral-to-harmful on fresh
   seeds; at 2200 it is harmful (24→29 collapses, +1.89 s/veh).
2. **The wall's value changes sign with loading.** Protection-at-a-price
   below ~2450; managed-discharge savings above ~2600. Collapse incidence
   stays ~1.0 above the boundary — the wall repairs discharge, it does
   not prevent collapse there.
3. **A fitted three-output escalation policy.** Detect onset; escalate
   when observed loading exceeds a counterfactually located threshold;
   hold a loading-dependent duration.
4. **Observability limits.** Whether is one-dimensional. Per-realization
   Δdelay at fixed loading is not predictable from aggregate RSU state.
5. **Cost accounting.** Zero collisions/teleports; low-TTC flat;
   systematic decel-cap exposure at the wall tail, reported by location
   as a comfort cost (not a safety veto). The −4.5 m/s² "hard-brake"
   metric is the IDM `decel` cap.

**Do not claim:** individual treatment-effect prediction; collapse
prevention at 2600–2700; that a multi-feature model is required for
whether; the legacy 0.86→0.08 / 0.48 numbers as current evidence;
Krauss results as primary IDM evidence.
