## Built
- Flag-gated black-box model (`wms/model.py --black-box`): every present vehicle is a learned
  mover; CAVs are conditioned only on a controller-id embedding (`none/native/pi/damping/wall/
  other`) + state history. Structured WM-S ignores the embedding and teacher-forces CAVs as
  before. Same `collate`, losses, curriculum, truncation, `check400` for both — the controller
  enters the black-box only as an input feature.
- C1 protocol (`wms/c1.py`, pure arrays): car-level |ds| median on CAV-affected HDVs at
  10/30/120/300 s; per-section speed/queue/delay error; paired PI-native difference (mean signed
  error, sign agreement, Spearman); seen-vs-unseen error ratio; `protocol_descriptor()`.
- LPO selection (`wms/lpo.py`, metadata only): trains on `windows_train_noPI.json`, validates
  on `windows_val.json`, evaluates on `pi_eval_states.json`. Matching is the structured
  `(batch, world, arm, t0_s)` id because pack_v3 reuses `chunk` across the old/`truearms`
  batches; exclusions match the source batch only; fails closed on any absent keep key.
