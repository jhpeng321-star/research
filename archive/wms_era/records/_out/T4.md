## Model (wms/model.py)
a = a_phys(IDM, SUMO-fidelity params, s_down frame, bumper gaps, accel-lane end as standing obstacle, open road) + g(k)*(HdvResidualNet delta + history/k MLP delta).
g(k)=cumsum(softplus(inc))[k-1], g(0)=0 exactly, monotone. k = steps since last real observation (rollout step index).
Lane = MOBIL(IDM incentive, b_safe(u))+mandatory-merge baseline logits (stay=0, move=3tanh(dA/4)-2.5+6u^2, merge zone [0,75.44] s_down, 2->1 only) + g(k)*learned lane delta.
History: rolling [K,10,6] buffer (v,a,lane1hot,gap) fed with the model's own states; initial from real pre-t0 ticks (same-vehicle continuity from target_mask, never crossing run start).
CAVs teacher-forced (no gradient); exits/presence teacher-forced from the pack alive mask.
Torch physics (wms/physics_torch.py from wms/torchphys) is merged but NOT used by the trainer; its 4 parity tests fail after merge (not investigated, not on the training path).
## Trainer (wms/train.py)
Real A11 packs via IdeaACorpus INDEX run ranges + identity sidecars (3 packs, 3060 TRAIN windows). Optional --start-shift-prob (default 0 in dry-run; chain uses 0.75): window starts at a random later tick of its run so real pre-t0 history exists (pack items start 1-3 ticks after run start, so unshifted windows have no history); identity row not used for shifted windows.
Loss: position Huber(5 m)+speed Huber(1 m/s)+lane CE, one global valid-HDV-count normaliser, step weights exp(-0.01 i). Chunked truncated BPTT: backward every 20 steps, so activation memory is constant in unroll length (10/30/60/120 s same memory). Curriculum 10->30->60->120 s with per-stage steps; per-stage checkpoints.
