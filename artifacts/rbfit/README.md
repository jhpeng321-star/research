# Observable-motion physical fits

Results generated on cpuQ using the existing NumPy/SciPy environment.
Versioned output directories are preserved. `gaussian_v1/` is the first complete
fit and has worse per-driver RMSE tails than its pooled baseline; it is evidence,
not an adopted WM-PHYS configuration. The final recommendation is in HANDOFF.md.

No assignment/type/truth files or non-FIT worlds are inputs. Provenance hashes
bind the six allowlisted observable files for each of 32 native episodes.
