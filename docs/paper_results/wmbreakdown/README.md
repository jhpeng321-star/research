# WMBREAKDOWN evidence

Task-owned observable reductions, source hashes, per-run CSVs, distributional
scores and figures. Reproduction and estimands: `tools/wmbreakdown/README.md`.
No simulated or imagined trajectories are generated by this analysis.

- `real_events.csv`: 4,500 BIC decisions (500 episodes × 3 regions × 3 horizons).
- `real_probability.csv`, `real_shifts.csv`: arm and demand×penetration rates,
  Wilson intervals, onset summaries and paired shifts vs native/CTRL0.
- `real_paired.csv`, `gain_by_breakdown.csv`: per-world categories and delay
  gains; the latter excludes native as an action arm. Positive gain is good.
- `forecast_draws.csv`: 13,440 canonical K8 scalar predictions, two clocks.
- `distribution_worlds.csv`, `distribution_summary.csv`, `pit_histogram.csv`:
  CRPS/baselines, coverage, spread, bias and nine-bin rank PIT. Team clock is
  primary; objective clock is a sensitivity. Effect = arm minus CTRL0 (negative
  is good), whereas the real pairing CSV's gain uses the opposite sign.
- `expected_effects.csv`, `expected_effect_skill.csv`: group expectations and
  cell-wise sign/order agreement. A one-world cell has no bootstrap CI.
- `forecast_audit.json`: canonical task hashes, start identities, explicit
  missing shard identities, producer/scorer hashes and trajectory availability.
- `verification.json`: source-receipt checks, independent numerical checks and
  output hashes. Bootstrap intervals here are pointwise diagnostics, not the
  proposed simultaneous qualification bands.
- `real_breakdown.png`, `wm_distribution.png`: the two report figures.
