# WM-PHYS credibility publications

S-RB-DECIDE publishes versioned, immutable credibility sections here, with a
separate directory per model and portable relative figure links. Full row-level
statistics remain in the hash-bound local `runs/wmdecide_*` source reports.

`tools/wmdecide/publish.py` checks all source report output hashes and, with
`--matched`, requires exactly the same scored worlds across models. These
publications are retrospective diagnostics, not the EVAL adoption gate or
closed-loop picker-policy results. Keep source/model versions distinct.
