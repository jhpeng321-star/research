# WM-N1 GPU plan (`bundle/GPU_PLAN.md`)

**Owner decision (2026-10-01):** all rented GPUs (3-4 boxes) run WM-N1
configs:

- Idea A members 1-5 (member-1 first),
- the variant **N** comparator members 1-5 (v1 pure-neural; member-1 first
  inside their own family),
- the three held-out-strategy tests (i)-(iii), one 1-member model each.

The multibox queue's default fleet is exactly **one config per box** (13
logical boxes). This document packs those 13 configs onto **3** and **4
physical boxes** so several configs run sequentially on a box while boxes run
in parallel. It is generated by `bundle.multibox.plan_fleet`:

```
python -m bundle.multibox plan-fleet --boxes 3   # table
python -m bundle.multibox plan-fleet --boxes 4 --json
```

## Design GPU-hour estimates (amendment 3 A3.7)

| config family | envelope (GPU-h) | point (midpoint) |
| --- | --- | --- |
| Idea A member (`member-k`) | 9-17 | 13.0 |
| variant N member (`n-member-k`) | 5-10 | 7.5 |
| held-out test (1 member, as Idea A) | 9-17 | 13.0 |

Idea A member 1 alone is 9-17 GPU-h (A3.7). The tables below use the midpoints;
`wall_clock_hours` is the maximum box finish time. Bounds computed with the
low/high per-config envelopes: **3 boxes 37.0-71.0 h**, **4 boxes 28.0-54.0 h**.

## Scheduling rules

1. **Idea A `member-1` is box 1's first job** at t=0.
2. **`n-member-1` is box 2's first job** at t=0 (independent family head).
3. Every other `member-k` / `n-member-k` (k>1) is released only when its own
   family's member-1 finishes (amendment 1 A1; amendment 3 A3.3 for N).
4. Held-out tests are independent 1-member models (release t=0).
5. The remaining jobs are list-scheduled (earliest finish, ties to the lowest
   box id) to minimise wall-clock.

## Approval and safety (unchanged)

Each config keeps its **own** owner `APPROVAL.json`, which binds that config's
written `TIMING_GATE.json` sha256 and the four frozen records (registration +
amendments 1-3, LF-normalised). No member trains before its approval exists;
member-k (k>1) refuses until its family's member-1 has completed. See
`multibox.py` and `README.md`.
