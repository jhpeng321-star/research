# S-COOPBEHAV evidence

Derived observable-trajectory reports only; no simulator state, checkpoints,
truth labels, assignment files or raw research trajectories are copied here.
`WMDATA_final/` and `WMDATA2_final/` are the selected CPU analysis outputs.
Input array SHA256s and source episode metadata are in each `inputs.json`.
Launch/PID receipts and the executed code archive digest are retained separately.
These are descriptive controller comparisons, not member-release causal tests.

`FINAL_COMPARISON.json` selects the final descriptive reports and the81-pair
probe snapshot beginning `a0b825aa936d`. `live/` contains cumulative immutable
paired snapshots published by the watcher; do not pool them. The paper document
names its exact snapshot. Native-release and policy-mean reference kinds remain
distinct in event records.

`WMDATA2/`, `*_v2/`, `COMPARISON.json` and the24-pair snapshot beginning
`45784334168f` are pilot/QA history, not the final analysis. Some pilot openings
were not ended on recovered braking displacement and fail the final physical
QA. Their data are retained, not deleted or silently rewritten. The37-pair
snapshot is an earlier, overlapping valid snapshot. Local verification metadata
and the watcher receipt are additional to the copied remote outputs.
